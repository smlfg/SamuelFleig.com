# docs/

Tiefere Doku zur samuelfleig.com-Site. Der Einstieg fuer Besucher ist
`README.md` im Repo-Root; diese Datei ist die Inhaltsübersicht fuer
Mitwirkende und zukuenftige Micha.

- `REPOSITORY_MAP.md` — was lebt wo im Repo (Rolle der Top-Level-Pfade,
  Abgrenzung zur Live-Site und zur Werkstatt)
- `MANIFEST.md` — was dieses Repo oeffentlich macht und was bewusst draussen
  bleibt (Sicherheits-, Datenschutz- und Privatsphaere-Grenzen)

Konvention: Inhaltsaenderungen an der Site gehoeren in `index.html`,
`style.css`, `script.js` und `fonts/`. Alles, was nur Doku ist, gehoert hier
rein.
